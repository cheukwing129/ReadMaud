# Asset sources

- `paper-texture.png` and `paper-gloss.png`: original background assets from [NIPPON COLORS](https://nipponcolors.com/), retrieved from `/images/texture.png` and `/images/gloss.png`. Used at their native CSS size, without an opacity reduction, to match the requested reference. Original artwork remains the property of its respective owners.
- `source-han-serif-tc.woff2` and `source-han-serif-tc.ttf`: modified character subsets derived from Adobe's [Source Han Serif Traditional Chinese Regular](https://github.com/adobe-fonts/source-han-serif). Internal font family renamed to **ReadMaud Source Serif** in accordance with the reserved font name requirement. The web version retains CFF outlines; the PDF version uses converted TrueType outlines. Covered characters include the current article collection and reading interface. See `SourceHanSerif-LICENSE.txt` for the SIL Open Font License 1.1 and copyright notices.
- `dm-sans-variable.ttf`: DM Sans variable font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/dmsans), self-hosted for the Latin interface. See `DM-Sans-LICENSE.txt` for its SIL Open Font License 1.1.
