# Asset sources

- `paper-texture.png` and `paper-gloss.png`: original background assets from [NIPPON COLORS](https://nipponcolors.com/), retrieved from `/images/texture.png` and `/images/gloss.png`. Used at their native CSS size, without an opacity reduction, to match the requested reference. Original artwork remains the property of its respective owners.
- `source-han-serif-tc.woff2` and `source-han-serif-tc.ttf`: modified character subsets derived from Adobe's [Source Han Serif Traditional Chinese Regular](https://github.com/adobe-fonts/source-han-serif). Internal font family renamed to **ReadMaud Source Serif** in accordance with the reserved font name requirement. The web version retains CFF outlines; the PDF version uses converted TrueType outlines. See `SourceHanSerif-LICENSE.txt` for the SIL Open Font License 1.1 and copyright notices.
- `source-han-serif-tc-fallback.ttf`: a small TrueType subset of Noto Serif TC, derived from Adobe Source Han Serif, containing uncommon Traditional Chinese characters that were absent from the primary PDF subset. It is used only for those glyphs during PDF export; it uses the same SIL Open Font License 1.1 terms in `SourceHanSerif-LICENSE.txt`.
- `source-han-sans-tc.woff2`: Google Fonts 的 [Noto Sans TC](https://github.com/google/fonts/tree/main/ofl/notosanstc)，字形源自 Adobe 的 [Source Han Sans](https://github.com/adobe-fonts/source-han-sans)；固定使用 Regular 400，並只保留目前文章及介面需要的字元。內部字體名稱改為 **ReadMaud Source Sans**。Noto Sans TC 未收錄的 `U+9B3D`（「鬽」）由既有思源宋體子集補足。見 `SourceHanSans-LICENSE.txt`（SIL Open Font License 1.1）。
- `dm-sans-variable.ttf`: DM Sans variable font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/dmsans), self-hosted for the Latin interface. See `DM-Sans-LICENSE.txt` for its SIL Open Font License 1.1.
